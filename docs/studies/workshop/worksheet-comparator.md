# Optional tag-heavy worksheet comparator (condition B)

This is a printable study control. It is not a product proposal or a required
setup gate. The author may leave every tag blank. **Unchecked or blank means
unspecified; it does not mean excluded or false.** Free text is always allowed.

The author completes the sheet before the generic Develop request. The author
must read the assembled instruction, correct it if needed, and explicitly check
it before manually sending. The facilitator records the final assembled text or
its hash only in the anonymous observation form, subject to the author's choice
to share it.

## Final assembled instruction check

The facilitator or author writes the single exact instruction that will be sent
through the generic Develop route. Copy the assigned task prompt, then include
only checked Want tags, checked Avoid tags, and nonblank optional fields. Do not
silently add blank tags as negatives or add alternate exploration requests.
After the response, the author chooses two details and one world decision; the
worksheet does not pre-decide those choices.

```text
Task: [copy the exact matching task prompt]
Want tags: [list only checked Want tags; omit this line if none]
Avoid tags: [list only checked Avoid tags; omit this line if none]
Author meaning: [optional; omit if blank]
Protected details: [optional; omit if blank]
Open questions: [optional; omit if blank]

```
