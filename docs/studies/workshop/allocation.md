# Counterbalanced allocation

Assign condition and seed using the separate columns below. The condition sequence controls the
order in which A, B, and C are experienced. The seed sequence controls which of
S1, S2, and S3 is used in positions 1, 2, and 3. Do not always pair a seed with
the same condition.

## Six-row balanced block

For participant IDs in order, use the next unused row and then start a new
six-row block. The first three rows interleave the forward condition orders so
a typical group of three does not put every participant in the same first
condition. The last three rows add the reversed sequences when the group is
large enough. Seed positions stay explicit and the condition/seed pairings
rotate across each three-row block.

| Row | Condition order (positions 1–3) | Seed order (positions 1–3) |
| --- | --- | --- |
| 1 | A B C | S1 S2 S3 |
| 2 | B C A | S3 S1 S2 |
| 3 | C A B | S2 S3 S1 |
| 4 | C B A | S3 S2 S1 |
| 5 | B A C | S1 S3 S2 |
| 6 | A C B | S2 S1 S3 |

Within rows 1–3, each condition is paired with S1, S2, and S3 exactly once;
rows 4–6 repeat that property for the reversed block. Each seed also occupies
each task position once within each three-row block. Neither seed identity nor
task position is tied to a condition. If fewer than six
participants complete the block, retain the assigned row rather than
reassigning after seeing results. If a participant stops early, keep the
partial row and mark missing cells.

If a second block is needed, reuse rows 1–6 in order and record the block
number. Do not change a row after seeing a result. If fewer than 18 completed
condition exposures are available (fewer than six participants when all three
conditions are complete), report the exact rows used, every completed
condition/seed cell, every missing cell, and the reason for each missing cell.
Show raw counts and the maximum-minus-minimum range for conditions and seeds;
do not call the result balanced, estimate an unobserved cell, or create
participant rows to complete a block.
