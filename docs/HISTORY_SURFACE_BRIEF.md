# Saved versions

Mode: Operate. This is a local addition to the existing writing desk.

## Direction contract

THESIS: Compare earlier prose beside current writing, then explicitly restore one saved version.

OWN-WORLD: Inherit the white manuscript, slate controls, muted blue actions, Segoe UI chrome, and Georgia prose.

STORY: The author chooses a dated saved version, reads it without altering the editor, and restores it knowing the current writing remains in history.

FIRST VIEWPORT: Keep the live manuscript on the left. The right panel contains a version selector, readable historical prose, and a clearly separated Restore this version action. Loading, empty, stale, and failed reads are explicit.

FORM: Extend the established writing desk directly; no identity or concept selection. Selection changes replace only the read-only preview. Restore uses the existing short editor barrier.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
