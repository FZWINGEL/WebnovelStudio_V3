# Draft export surface

Mode: Operate. Extend the existing writing desk with a focused modal.

The author chooses a format, reads the exact saved output and formatting limitations, then selects a destination. Keep the document title and saved version visible. No file is created merely by opening or refreshing the preview.

Use the established white/slate palette, muted blue action, Segoe UI chrome, and a readable monospaced file preview. This is a local dialog, with no new product identity or imagery.

Keep format selection, the scrollable complete preview, and the explicit destination action reachable in a small viewport. Loading, empty output, cancellation, existing destination, completed export, and possible post-install failure need distinct plain-language states. Restore focus to the launch button. Test real native Save and Cancel separately from browser component tests.

Finish review and evidence are recorded in `DESIGN.md` and implementation status. No raster assets are introduced.
