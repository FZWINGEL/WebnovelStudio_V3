# V2 import preview foundation

`webnovel_core::v2_import::preview_v2_import(path, source_project_id)` returns a bounded preview for one explicitly selected V2 project. It does not create a V3 project, install legacy rows, expose an Import action, or change V2. The source must be a stable schema-8 database copy; live SQLite sidecars are refused. Only synthetic fixtures have been used for this slice.

The preview retains the source schema and migration ledger, copied-byte fingerprint, selected project identity, chapter ordering and retirement state, draft pointers, and inert legacy records with counts. It validates the complete expected table/column contract, migration names, database integrity, foreign keys, project ownership, and generic record references before returning the result. Source size is capped at 512 MiB; retained legacy JSON at 4 MiB and 20,000 rows. The limits cause refusal rather than truncation.

On Windows the reader holds a read-sharing source handle that excludes concurrent writers and deletion while copying. It copies bounded chunks into an owned temporary directory, hashes the copied bytes, and reads the owned database inside one SQLite read transaction. Every exit path cleans the copied database and known sidecars. The original database is never opened through SQLite on this path. An active V2 writer must be closed or a stable copy supplied. Persistent WAL mode is also refused from the file header, even when no sidecar remains. Non-Windows calls return `UnsupportedPlatform` before opening the source; portable import requires separate qualification.

Eight Windows fixture tests cover independent projects, exact prose states, retained history, schema/ledger/table/column refusal, foreign references, source preservation, and sidecar/WAL-mode refusal. A separate non-Windows guard test asserts refusal and unchanged source. Windows tests and Clippy passed; a local Linux cross-target check was unavailable because that target toolchain is not installed. Hosted Ubuntu CI remains the cross-platform compile gate.

`working_prose = NULL` and `working_prose = ''` are different states. Present working prose, including an intentionally empty string, remains exact. A chapter without working prose is marked as requiring an author choice; draft approval flags do not silently choose a V3 manuscript or establish reviewed authority. Retired chapters remain visible in the preview. Historical drafts, decisions, options, and other rows remain inert evidence.

The next F1 slice must add explicit body choices, a versioned import manifest and ID mapping, durable legacy evidence inside the V3 backup boundary, staged installation with a new project identity, and resumable/replay-safe import acceptance. It must test the completed project, source preservation, backup/recovery, and failure cleanup before offering an author-facing Import action. This preview does not complete F1 or establish V3 canon from legacy approval flags.
