# Trial icon source

`icon.svg` is original vector geometry authored for this repository on 5 September 2026. `icon.ico` was generated from that exact source with the locked Tauri CLI 2.11.4. It is a development icon, not a final product identity or a third-party image.

To regenerate, run the Tauri `icon` command against `src-tauri/icons/icon.svg` with an output directory under the repository's ignored `.local/`, then copy only `icon.ico` into this directory. The other platform outputs are outside the Windows W0 scope.
